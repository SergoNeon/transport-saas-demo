# בקרת דרך - מבחן מקצועי למבקרי תחבורה ציבורית

אפליקציית אינטרנט (HTML/CSS/JavaScript, ללא שירות חיצוני) המציגה את 30 השאלות ממבחן ההכשרה שנבנה ב-28.10.2026.

## תכונות

- עברית מלאה, ממשק RTL נוח לנייד ולמחשב.
- התחלה עם שם עובד ומספר עובד (רשות).
- 30 שאלות רב-ברירה, שאלה אחת בכל מסך, מעבר ישיר בין שאלות.
- שעון של 40 דקות, הגשה אוטומטית בסיום הזמן.
- שמירת התקדמות מקומית בדפדפן, חידוש לאחר סגירת הדף.
- ניקוד אוטומטי, ציון מעבר מוצע 24/30 (80%).
- שיתוף סיכום תוצאה, הורדת דוח CSV והדפסה / שמירה כ-PDF.

## הפעלה

להצגה מקומית: פותחים את `index.html` בדפדפן מודרני. לפריסה: לפרסם את התיקייה כאתר סטטי ב-Vercel/Pages.

## אבטחה והגבלות

גרסת הדרכה ראשונית. תוצאות נשמרות רק ב-`localStorage` במכשיר הנבחן, ולא במסד נתונים מרכזי. שיתוף התוצאה דורש פעולה יזומה של הנבחן. מפתח התשובות נכלל בקוד JavaScript לצורכי בדיקה מקומית, ולכן **אין להשתמש במערכת זו למבחן הסמכה מאובטח או כבסיס לתוצאה בלתי ניתנת לשינוי**. לשם כך יש להוסיף ממשק מנהל מאומת, שמירת תוצאות בשרת ומנגנון בדיקה בצד השרת.

השאלות והסברי התשובות הם חומר הדרכה מוצע בלבד; יש לאשרם מול הנהלים העדכניים של החברה ומשרד התחבורה לפני שימוש מחייב.
