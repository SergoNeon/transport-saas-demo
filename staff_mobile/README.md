# BRILL STAFF - אפליקציה לעובדי שטח

ממשק מלא בעברית ו-RTL. גרסת Flutter נבנית לאנדרואיד ולהדגמה באינטרנט מאותו קוד.

## היכן בודקים
- דמו אונליין לאחר השלמת CI: https://sergoneon.github.io/transport-saas-demo/staff-app/
- APK לאחר השלמת CI: GitHub Releases בשם brill-staff-demo.
- כל העובדים ומיקומי העבודה בדויים בלבד.

## יכולות הדגמה
- מנהל: כל העובדים, סטטוס משמרת, שעות עבודה והפסקות.
- עובד: כניסה, הפסקה, חזרה, יציאה.
- חישוב שעות נטו בניכוי הפסקות.
- מפת מקומות עבודה: מציגה מיקומי דמו לעובדים פעילים בלבד.
- דוח שעות בעברית והעתקת CSV.
- שמירת נתוני ההדגמה מקומית, סימולציית 15 דקות, איפוס.

## בטיחות ופרטיות
אין הרשאות GPS, אין מיקומים אמיתיים, אין התחברות לשרת עובדים או חשבונות אמיתיים.
תצוגת מנהל ועובד הן סימולציות, ולא בקרת גישה. אין להשתמש בהדגמה לצורך נוכחות ושכר אמיתיים.

## לפני ייצור
נדרשים חשבונות אמיתיים והרשאות נפרדות, PostgreSQL, דיווחי שעות חתומים בשרת,
הגנת מידע ונהלי שמירה, הרשאות מיקום במהלך משמרת פעילה בלבד, ניהול אופליין,
חתימת APK/AAB להפצה ואימות חוקיות הפיקוח לפי הדין בישראל.
יש לבצע בדיקה בטלפון אנדרואיד ובמחשב.
